# Requirements

## v1 Requirements

### 输入与生成 (INPUT / GEN)
- [ ] **INPUT-01**: 用户可从常用食材库多选食材
- [ ] **INPUT-02**: 用户可手动输入自定义食材
- [ ] **INPUT-03**: 用户可从常用调味料库多选调味料
- [ ] **INPUT-04**: 用户可手动输入自定义调味料
- [ ] **INPUT-05**: 用户可选择菜系（川/粤/家常/西餐/日韩等）
- [ ] **INPUT-06**: 用户可选择口味偏好（辣/清淡/酸甜/咸鲜）
- [ ] **GEN-01**: 点击生成后基于以上条件匹配出 1-3 个菜谱
- [ ] **GEN-02**: 匹配结果按契合度排序（食材覆盖率优先）

### 菜谱展示 (DISP)
- [ ] **DISP-01**: 菜谱展示名称、所需食材、所需调味料、步骤
- [ ] **DISP-02**: 菜谱支持"换一换"重新匹配
- [ ] **DISP-03**: 菜谱详情页可单独访问（带 path 参数）

### 收藏与历史 (FAV / HIST)
- [ ] **FAV-01**: 用户可收藏/取消收藏菜谱
- [ ] **FAV-02**: 收藏页列出所有收藏的菜谱
- [ ] **HIST-01**: 历史记录页列出按时间倒序的生成结果
- [ ] **HIST-02**: 历史记录可单条删除

### 分享 (SHARE)
- [ ] **SHARE-01**: 菜谱详情页支持分享给微信好友（不含朋友圈）
- [ ] **SHARE-02**: 分享卡片点开进入对应菜谱详情
- [ ] **SHARE-03**: 分享时显示菜名 + 简介

## v2 Requirements (Deferred)
- AI 生成菜谱（DeepSeek 等）
- 分享到朋友圈
- 食材图片识别
- 营养信息
- 视频步骤
- 多语言

## Out of Scope
- 用户系统/登录 — 纯本地应用，无后端
- 云端菜谱同步 — 不做云
