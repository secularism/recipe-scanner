# 菜谱生成小程序 (recipe-scanner)

## What This Is

一个微信小程序，用户输入/选择自己有的食材和调味料，再选菜系和口味偏好，本地匹配生成可做的菜谱。支持收藏、历史记录、分享给微信好友（不含朋友圈），分享卡片点开直达菜谱详情。

## Core Value

**用户输入食材和调味料 → 立刻得到一份可做的菜谱**，无需思考"今天吃什么"。

## Tech Stack

- **框架**: uni-app (Vue 3 + TypeScript + Composition API)
- **构建**: vue-cli 5 (@vue/cli) + @dcloudio/uni-cli-shared-presets
- **目标平台**: 微信小程序（主），H5 兼容
- **UI 库**: uni-ui
- **状态管理**: Pinia (轻量、Vue3 原生)
- **存储**: uni.setStorageSync (本地) — 收藏/历史
- **路由**: uni-app 内置 + 微信 onShareAppMessage / onShareTimeline 替代品
- **代码规范**: ESLint + Prettier + TypeScript strict

## Constraints

- 微信小程序主包 ≤ 2MB（避免资源/页面/数据过大）
- 单个文件 ≤ 300 行（保持模块清晰）
- 全部本地匹配 — 不依赖外部 API（首版）
- 离线可用 — 断网下完整功能

## Key Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| 本地规则匹配而非 AI | 响应快、离线可用、零成本；AI 留扩展点 | 已实现 |
| Pinia 而非 Vuex | Vue3 官方推荐、API 简洁 | 已实现 |
| 单数据源菜谱库 | 食材/调味料/菜系/口味/步骤集中管理 | 已实现 |
| 分享走微信 onShareAppMessage | 不上朋友圈；点开走 path 直达详情页 | 已实现 |
| uni-ui 而非手写全套 | 官方维护、跨端一致 | 已实现 |

## Requirements

### Validated

#### 输入与生成
- [x] **INPUT-01** 用户可从常用食材库多选食材
- [x] **INPUT-02** 用户可手动输入自定义食材
- [x] **INPUT-03** 用户可从常用调味料库多选调味料
- [x] **INPUT-04** 用户可手动输入自定义调味料
- [x] **INPUT-05** 用户可选择菜系（川/粤/家常/西餐/日韩等）
- [x] **INPUT-06** 用户可选择口味偏好（辣/清淡/酸甜/咸鲜）
- [x] **GEN-01** 点击生成后基于以上条件匹配出 1-3 个菜谱
- [x] **GEN-02** 匹配结果按契合度排序（食材覆盖率优先）

#### 菜谱展示
- [x] **DISP-01** 菜谱展示名称、所需食材、所需调味料、步骤
- [x] **DISP-02** 菜谱支持"换一换"重新匹配
- [x] **DISP-03** 菜谱详情页可单独访问（带 path 参数）

#### 收藏与历史
- [x] **FAV-01** 用户可收藏/取消收藏菜谱
- [x] **FAV-02** 收藏页列出所有收藏的菜谱
- [x] **HIST-01** 历史记录页列出按时间倒序的生成结果
- [x] **HIST-02** 历史记录可单条删除

#### 分享
- [x] **SHARE-01** 菜谱详情页支持分享给微信好友（不含朋友圈）
- [x] **SHARE-02** 分享卡片点开进入对应菜谱详情
- [x] **SHARE-03** 分享时显示菜名 + 简介
